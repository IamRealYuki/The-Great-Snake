Легендарная игра "змейка", реализаций которой чуть ли не больше, чем "Hello, World!"
имеет три типа фруктов, которые дают различные эффекты
Логика сделана при помощи принципов объектно ориентированного программирования, через полиморфизм и виртуальные функции
Платформа Windows. Для графики использовалась библиотека SFML
